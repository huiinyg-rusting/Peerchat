# Peerchat
一款直连加密聊天软件  
**半成品**  
一个简易的demo，支持DHT和局域网，当然还有更多广域网方案，但是我不打算适配了
## 仅用于学习用途，不允许商业
按照中国的惯例，这一类聊天协议的用途十分危险并且很容易逃避监管，所以一般是不予运营的。据此，这一款聊天软件只做Demo演示学习，不予使用，违者后果自行承担。  
但是我还是尽量做成一个学习样本，全部使用Rust+libp2p。还有海量的**中文注释**方便理解，推荐大家研读  
局域网直连的完整度很完善，可以保存聊天记录，私钥之类。DHT直连理论上是可以使用，但是我留下了一堆摊子，这样实际编译使用就有些困难。此外，这个项目的TUI也是挺好看的，可以借鉴一下  
这个玩意以后极大概率不会更新了
所以我的开源协议选的很严格
